## 研究テーマ

### 1. 視覚順応の EEG 研究（修士研究）
視覚順応における知覚と想起の脳活動を、行動データと脳波の時間周波数解析（ERSP）などで検討しています。修士論文の主題で、2027年3月までの論文投稿を目標にしています。

### 2. 視聴覚刺激に対する知覚・想起の EEG 研究
視覚・聴覚・視聴覚統合の条件で、知覚から想起への脳表現をデコーディングで解析しています。シーン（森／街、昼／夜）とオブジェクト（犬、カラス、車、ドローン）を刺激に用います。
**Society for Neuroscience（SfN）Neuroscience 2026 に採択**されており、2026年11月14〜18日に Washington D.C. で発表します。

### 3. Predictive Coding Network による継続学習（産総研）
Predictive Coding Network（PCN）における破滅的忘却を、Replay 手法（Input / Path / 併用）で抑える研究です。CIFAR-10・CIFAR-100・Tiny-ImageNet で、BP との比較を含めて検証しています。

### 4. 明晰夢の EEG 研究
研究設計・解析方針のレビュー・データ解釈を担う形で、チームで関与しています。

## 取り組み

- **K-NEURO** — 学部・学年・専攻を越えて、慶應の学生が神経科学の知見を共有する学生団体。サイトは [`k-neuro-site/`](k-neuro-site/) を参照。
- **ニューロアートバー構想** — 脳波連動の空間演出、モクテル、生演奏を組み合わせた体験の企画。
